# web_Xenia

Sitio corporativo DeepTech **XenIA** — tres demos de diseño.

## Desarrollo

```bash
cd /home/deep/Documentos/web_Xenia
npm install
npm run dev
```

Abrir http://localhost:5180

## Rutas

- `/` — selector de conceptos
- `/demo/scientific` — Scientific Future (**refinada**)
- `/demo/planetary` — Planetary Intelligence
- `/demo/industrial` — Industrial Intelligence
- `/teraval` — landing **independiente** Teraval (futuro subdominio)
